## 審查與限制

獨立程式碼審查指出拖曳中穿透狀態不同步，已修正：拖曳期間不記錄未套用的命中狀態，放開並限制位置後依最終視窗位置重新同步。審查者完成修正的靜態複查。

Windows Computer Use 嘗試取得桌寵視窗時，工具的應用程式授權逾時，因此沒有以該工具完成實體滑鼠拖曳、點擊穿透到背後軟體或多螢幕移動。上述自動化指標與拖曳訊息測試不能替代這些實體操作。音訊已驗證有輸出，聽感尚需使用者試聽。

正式安裝程式、程式碼簽章、效能基準測試、macOS 支援均不屬於這次交付。角色採簡易原創 SVG 動畫，音樂採短段合成器樂循環。
