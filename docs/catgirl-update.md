# 森森貓娘版 0.2

使用者已確認概念圖及開始實作。沿用短髮、貓耳尾巴、綠白服裝，增加八個圖像姿勢：待機、眨眼、摸頭、拎起、讀書、睡覺、伸懶腰、揮手。

本次為既有桌寵流程的局部更新。番茄鐘、音樂、資料儲存保持既有功能。

- [x] 先測試反應優先順序及逾時恢復，再接入角色狀態。
- [x] 用 ImageGen 依核准概念圖生成並去背，將原始透明圖集保存於 `src/ui/assets/mori-catgirl-atlas.png`。
- [x] Canvas 依規則圖集載入各姿勢；以實際繪製後 alpha 判斷命中，確保透明區域穿透。
- [x] 單擊揮手、雙擊開面板；保留 Enter/Space，增加可見工具按鈕。摸頭、拎起、落地、陪讀及閒置狀態相互切換。
- [x] 用實際 Electron 測試互動、畫面與舊功能，靜態審查後重新打包並驗證 Mori.exe。

素材來源：內建 ImageGen。參考已確認的 `exec-78659445-c2d8-459e-8123-339dae78b9dc.png`。生成提示：保留原創森森的髮型、綠眼睛、綠白衣服與比例，建立 4 欄 × 2 列圖集，依序為 idle/blink/happy/held/read/sleep/stretch/wave，無文字或背景；第二次處理只去除誤生成的棋盤格，輸出真正 RGBA 透明 PNG。原始輸出 `exec-9ca9e374-a652-4668-b64e-dfc4bfee4592.png`，1774×887。

這版使用姿勢切換與程序式呼吸、擺動、落地動畫，並非逐格完整骨架動畫。
