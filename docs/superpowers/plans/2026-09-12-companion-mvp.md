# 森日 0.3 陪伴 MVP

使用者已授權依產品評估開始調整。本次沿用現有本機 Electron 架構，直接在目前非 Git 工作目錄執行。

## 交付與驗證

1. 計時模型：增加單輪 duration，讓 quickStart 的 5 分鐘不改掉使用者偏好的 25 分鐘；暫停續跑、重啟、重設與切換模式都使用正確時長。以核心測試確認完成一次、保存恢復與拒絕覆蓋進行中的專注。
2. 陪伴設定：presence 接受 companion/focus/quiet，panelPinned 接受 boolean，保存後恢復。一般面板預設不置頂；勿擾隱藏角色、抑制提示音與氣泡，計時與音樂繼續。工具面板及系統匣可恢復陪伴，Ctrl+Alt+M 暫時顯示／隱藏。
3. 回饋與記憶：從既有 days 推導有專注的天數、累計完成輪數、最近一次過往紀錄與三個永久里程碑；不虛構歷史、不扣除離線天數。完成一輪觸發短暫 happy 姿勢與文字，勿擾期間只留回憶紀錄。
4. 介面：5 分鐘入口、模式選單、釘選、收工與回憶卡；音景改成可展開區塊。一般氣泡只在互動、完成或滑入時顯示，專注模式只顯示必要提醒。收工暫停計時及停止音樂，保留待辦。
5. 使用既有 smoke 擴充真實視窗檢查：安靜氣泡、完成姿勢、釘選、勿擾不暫停、回復、5 分鐘、收工與重啟。檢視新截圖，更新 README 與 verification，再打包並驗證可攜版。

## 範圍界線

不增加雲端、商店、AI 對話或新美術依賴。多螢幕實體穿透與長時間效能仍需實機驗證，不能以自動派送指標事件取代。正式安裝與簽章留在公開發行前處理。
