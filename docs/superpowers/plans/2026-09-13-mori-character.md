# 森森角色更新

使用者要求更靈動的桌寵、新互動與待機動作、兩套新服裝。依此實作：奶油居家服／午後外出服與原服裝並存；每套含站立、讀書、拖曳及表情。待機動作採有間隔的隨機排程，互動優先，專注與減少動態收斂；不自動移動桌面視窗。

- 圖集生成、透明度檢查、實際大小視覺檢查；沿用先前使用者明確同意的本機去背方法處理不透明背景。
- 狀態加入服裝保存；主程序提供三個具冷卻的互動，前端有清楚可操作入口。
- 原子切换服裝，載入失敗保留舊角色；新圖集缺失不影響原服裝與工具。
- 先測待機排程、互動優先權與設定驗證，再驗證實際換裝、快速切換、動畫、暫停動態及既有功能。
- 更新可攜版與使用文件；不將這次圖集動態稱為完整骨架動畫。
