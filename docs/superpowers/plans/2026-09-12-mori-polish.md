# 森日 0.4 UI 與動畫精修

使用者已授權依 0.3 評估開始實作。主要驗收：常用操作不需捲動；讀書時摸頭保留坐姿；安靜陪伴有低頻眨眼。沿用既有 Electron 與本機保存，不加入新依賴。

1. `src/model.cjs`：完成任務清除選取，拒絕選取完成任務；刪除保留 8 秒暫存復原，保留原順序並尊重後來的選取；里程碑補上依歷史推導的取得日期。先寫核心行為測試。
2. `src/ui/panel.html`, `panel.js`, `styles.css`：頂部精簡、內容區單一捲動、底部統計與收工固定；待辦預設最多三項，查看全部；回憶冊預設收合、首片葉子可點開；新增復原提示；音量命中區放大；陪伴方式文字改為互動陪伴／安靜陪伴／隱藏並靜音。
3. `src/ui/pet-state.mjs`, `pet.js`：独立眨眼排程，不被讀書覆蓋，不漏掉低頻繪製時的眨眼；讀書摸頭用 readHappy，完成回饋保留坐姿；一般氣泡滑入延後 350ms，文字輪替與冷卻，兩行顯示。
4. `src/ui/pet-sprite.mjs`, `assets`：補讀書表情素材，統一坐姿畫面座標、腳底與頭部尺寸；站坐採短過渡，系統減少動態時停用位移與擺動。輸出素材需確認實際 alpha，不得交付棋盤格背景。
5. 延伸 `scripts/smoke.cjs`，測試任務復原、折疊、底部固定、坐姿摸頭與眨眼、滑入氣泡、舊功能及素材載入失敗；檢視預設與展開截圖，更新文件及 0.4 可攜版並驗證。
