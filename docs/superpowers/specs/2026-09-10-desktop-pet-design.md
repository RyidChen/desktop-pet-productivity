# 桌寵專注工具：第一版設計

日期：2026-09-10
狀態：使用者已確認本設計；第一版已實作。驗證結果與尚待實體桌面確認的項目見 `docs/verification.md`。

## 產品體驗

Windows 桌面上住著一隻 2D 小貓。使用者點它開啟專注工具，選擇今日任務，開始番茄鐘，播放輕音樂。面板收起後，小貓留下陪伴，計時與播放繼續。專注結束時用小泡泡與可關閉的提示音提醒。

第一版介面採繁體中文、暖白與鼠尾草綠，角色使用原創向量圖形搭配簡單動畫。小貓是可更換的設計預設，不沿用參考作品的角色或音樂資產。

## 方案選擇

1. **Electron＋原生 HTML/CSS/JavaScript（建議）**：同一套介面涵蓋桌寵與工具面板，現有環境已有 Node.js/npm。可使用透明視窗、置頂、滑鼠穿透與系統匣；代價是執行環境占用較大。
2. **Tauri＋網頁介面**：可作為後續評估方向，但目前環境未偵測到 Rust 工具鏈，需要額外建置設定。
3. **遊戲引擎**：適合將來擴充完整 3D 房間、複雜角色動畫；目前第一版沒有這些需求。

第一版採方案一，介面不加入前端框架或 UI 元件庫。

## 視窗與互動

- 桌寵視窗：透明、無邊框、預設置頂、不出現在工作列；角色約 140–180 邏輯像素高。
- 點擊角色展開或收合面板；拖曳超過小幅移動門檻才搬動桌寵，避免放開拖曳時意外開啟面板。
- 游標摸過頭部時短暫開心；一般狀態呼吸與眨眼，閒置時打盹，專注時讀書，休息時伸懶腰。
- 透明空白處讓點擊穿過，角色本身仍可互動；不用覆蓋整個螢幕的大視窗。
- 面板使用獨立小視窗，寬約 360 邏輯像素，出現在角色旁，靠螢幕邊界時改變展開方向。
- 面板有明確收合按鈕，Escape 也可收合；不自動搶奪其他軟體焦點。
- 系統匣提供顯示／隱藏桌寵、開啟工具與結束程式。結束程式會停止音樂和計時。
- 記住位置；螢幕配置改變或座標無效時移回可見工作區。

## 工具面板

面板由上而下排列：桌寵狀態、番茄鐘、目前任務與今日待辦、聲音控制、今日統計。以簡單區塊呈現，避免第一版引入多層導覽。

### 番茄鐘

- 預設專注 25 分鐘、休息 5 分鐘；可分別自訂 1–180 分鐘。
- 支援開始、暫停、繼續、重設；執行中鎖定時長設定。
- 選中的待辦名稱顯示於計時器旁；未選任務也能開始。
- 一輪結束顯示下一階段，由使用者按開始進入，避免無人在場仍累積完成輪數。
- 使用截止時間計算剩餘秒數，收合面板不影響計時。
- 電腦睡眠時暫停，喚醒後保留剩餘時間，等待使用者繼續；睡眠時間不計入專注紀錄。
- 重啟程式時恢復為暫停狀態，不將離線時間算成專注。
- 完成提示最多觸發一次；專注累積只算實際執行的專注秒數，休息與暫停不計。

### 聲音

- 內建一段以程式合成的柔和器樂循環，提供立即可試聽的輕音樂；不將環境噪音充當輕音樂。
- 另有可疊加的合成雨聲，音樂與雨聲各自有音量與開關。
- 支援匯入本機 MP3/WAV，使用系統檔案選擇器挑選，循環播放單一曲目；顯示曲名。
- 首次啟動不自動播放；使用者按播放後，面板收起仍持續。
- 重啟記住曲目與音量但不自動播放；檔案遺失或無法解碼時顯示可理解的錯誤並允許重新選取。

### 待辦與統計

- 新增、完成、刪除待辦；名稱修剪空白，最多 120 字，不接受空內容。
- 可選一項作為目前專注任務，完成任務不強制結束計時。
- 顯示當地日期的專注分鐘與完成專注輪數；跨午夜的秒數依日期分配。
- 所有資料留在本機，無帳號或雲端服務。

## 結構與資料

- 主程序：管理視窗、系統匣、計時狀態、睡眠事件、日期統計與本機儲存。
- 桌寵介面：角色、拖曳與點擊事件，根據主程序狀態切換動畫。
- 工具介面：番茄鐘與待辦操作、聲音播放；收合只隱藏視窗，保留聲音執行環境。
- 預載橋接：只提供具名操作與狀態訂閱，驗證輸入與訊息來源；網頁介面不直接存取 Node.js。
- 儲存：使用應用程式使用者資料目錄中的 JSON，包含設定、任務、按日期統計、計時快照與視窗位置。
- 使用暫存檔替換正式檔案以降低半寫入風險，保留最近備份。資料損毀時保留原檔並回復備份或預設，寫入失敗時提示，不假裝保存成功。
- 狀態變更時儲存，計時中定期保存快照；異常退出最多遺失一個快照間隔的專注統計，目標間隔 15 秒。
- 禁止任意外部導覽與任意程序執行，介面以文字方式呈現待辦內容。

## 驗收

1. 啟動後看到真正獨立於瀏覽器的透明桌寵，桌面空白區能正常點擊。
2. 拖曳不誤觸面板，面板在工作區內展開，收合與重新開啟保留狀態。
3. 計時開始／暫停／恢復／重設正確；收合面板仍計時，結束只提醒一次。
4. 音樂實際可聽、雨聲可混音、兩個音量獨立；收合面板不中斷聲音。
5. 待辦與設定重啟後保留；找不到音樂檔案可恢復操作。
6. 以自動化檢查覆蓋計時切換、跨日統計、重複完成事件及儲存回復；視窗透明、穿透、拖曳與聲音需要桌面實測，分別記錄結果，不以瀏覽器預覽代替。

## 後續範圍

首版不包含完整房間、爬其他軟體視窗、多角色、商店、連續登入獎勵、AI 對話或串流平台整合。先確認陪伴感、操作與專注流程，再決定擴充。
