# 0.4 讀書表情素材

成品：`src/ui/assets/mori-reading-atlas.png`，RGBA 2172 × 724，四格由左至右為讀書、讀書眨眼、坐姿微笑、蹲下過渡。

使用內建 ImageGen，沿用既有森森造型。生成要求包含相同服裝、比例、坐姿與腳底基準，前三格只改眼睛／表情，第四格保持拿書並稍微起身蹲下。工具產出了 RGB 棋盤格，因此原輸出沒有可用透明度。

原始輸出保留於開發者本機，不隨儲存庫上傳。2026-09-12 使用者明確同意「可以，使用本機程式去背」。依此使用 `scripts/cutout-reading.py` 去除與外圍相連的中性灰底，保留每格角色的連通區域；未覆寫原圖。此處是處理記錄及生成要求摘要，非原始逐字提示。

程式透過 alpha 裁切、共用讀書比例及頭部錨點呈現；四格素材可隨可攜版一起搬移，不依賴原始輸出路徑。主圖集與補充圖集各自具有失敗回退。
