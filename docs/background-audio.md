# 0.4.3 本機背景音

`scripts/generate-backgrounds.py` 使用固定亂數種子及頻域塑形產生原始棕噪音、粉紅噪音及合成海浪，沒有取用外部音源或生成服務。輸出為 32 秒、32kHz、雙聲道 PCM16 WAV，位於 `src/ui/assets/music/{brown,pink,ocean}.wav`。

棕／粉紅噪音的功率頻譜斜率分別約 -1.99／-1.01（100–3000Hz），低頻漸減以避免直流及過低頻，並柔化高頻。海浪以塑形噪音加上緩慢音量起伏製作，起伏週期整除循環長度。音源在頻域生成為週期訊號，接點取樣差值通過相對於平常取樣差值的檢查。生成量測記錄於 `artifacts/background-audio-results.json`。

音量不代表主觀響度完全一致，海浪也不等同自然錄音。已做客觀頻譜、峰值、接點及實際程式播放檢查；仍可由使用者依聽感調整獨立背景音音量。
