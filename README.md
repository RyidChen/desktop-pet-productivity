# 森日 Mori

住在 Windows 桌面上的 Q 版貓娘森森，陪你慢慢完成今天的小事。

## 從 GitHub 取得原始碼

此儲存庫不包含個人待辦／專注紀錄、測試資料與截圖、`node_modules`、快取及 `dist` 可攜版。請依下方開發步驟執行 `npm ci`、`npm start`；可用 `npm run package` 自行產生可攜版。

本儲存庫包含十二首由專案擁有者提供並確認為 AI 創作的音樂；擁有者於 2026-09-17 明確要求將音檔上傳本公開儲存庫。加上程式合成的「午後窗邊」，共有 13 首內建音樂；雨聲、棕噪音、粉紅噪音與海浪也可離線使用。

程式碼、角色圖集與音樂的上傳不代表額外授予開源或素材再散布授權；本專案尚未指定授權條款。

## 開啟

雙擊專案根目錄的 **Start Mori.cmd**，或 **dist/Mori Focus/Mori.exe**。

可攜版不需要另外安裝 Node.js。搬移或分享時請帶走整個 `dist/Mori Focus` 資料夾，不能只複製 exe。這是未簽章的開發預覽版，尚未製作正式安裝程式。

## 使用

- **分層待機試作（0.7）**：經典森綠服、奶油居家服與午後外出服在站立待機、眨眼、摸頭、張望與專注閱讀時，使用獨立身體、頭部、左右耳與尾巴圖層。尾巴擺動、耳朵抽動、頭部隨游標轉向；安靜陪伴與減少動態效果抑制額外動作。專注閱讀改用清晰的低頭看書表情與坐姿捧書圖層，支援輕微點頭、眨眼及慢速擺尾（0.7.5）。睡覺、伸懶腰、打哈欠、吃點心與打招呼使用原姿勢的局部變形動畫（0.7.3），三套服裝都支援。拖曳保留原有擺動。這是 Canvas 分層關節動畫試作，不是完整 Live2D 模型；眼睛使用開／閉表情替換，尚無獨立眼球或髮束。分層素材載入失敗時自動回退原圖集。

- **五首新配樂（0.6.4）**：雨後花房、雲端漂流、楓糖小屋、星際慢車、竹影茶間，內建音樂共 13 首。沿用音量平衡、頭尾淡入淡出，支援單曲循環、隨機及依序播放。

### 0.6 日常操作改善

- **音樂選單（0.6.3）**：音樂與背景音各自使用整行選單，保留完整內建曲名；匯入音樂的檔名在選單下方自動換行，不需要等走馬燈。

- **使用說明**：首次打開面板顯示可略過的短引導，右上「使用說明」隨時可重看；關閉後保留偏好。
- **桌邊倒數**：專注或休息進行中、以及已暫停的未完成輪次，角色上方顯示時間與暫停／繼續，與對話氣泡共用位置；說話時暫時切換為對話，結束後恢復倒數。安靜陪伴也可使用；可在使用說明關閉顯示。系統匣懸停可看倒數。
- **捲動時的精簡計時列**：展開待辦或音樂往下捲動後，面板上方保留倒數與暫停／繼續。
- **復原計時**：已有進度時，重設、切換專注／休息、套用時長後，可在 8 秒內復原原本的本輪倒數。復原後保持暫停，已累積專注時間不重複計算；新開始計時後不再提供復原。此功能只復原本輪，不還原已套用的預設時長，也不跨重啟保存。
- **修改待辦**：每項小事右側的鉛筆可修改名稱；保留完成狀態、目前選取與正在進行的計時。
- **服裝預覽**：衣櫥直接顯示三套服裝，點預覽可換裝；選取項目標示「已穿上」。
- **隱藏角色與提醒**：原「隱藏並靜音」更名，明確表示音樂與倒數繼續。若要停止音樂與背景音，可各自按停止，或用「今天先到這裡」一起結束。


- **衣櫥與互動（0.5）**：右上衣服圖示可選經典森綠服、奶油居家服、午後外出服；重新開啟保留服裝。小點心、逗逗森森、休息一下會觸發短暫回應，不影響計時；互動間隔約 3 秒。
- **靈動待機（0.5）**：不定時左右張望、歪頭、伸懶腰，睡前打呵欠；滑鼠靠近有輕微朝向回應。閱讀和拖曳優先於待機動作，安靜陪伴與系統減少動態效果會抑制額外擺動。

- **陪伴方式**：互動陪伴保留摸頭與招呼，氣泡自動收起；滑到角色身上稍停可看倒數。安靜陪伴停止連續擺動，保留眨眼與完成提醒。「隱藏角色與提醒」隱藏角色並抑制提示，計時與音樂持續。
- **先做 5 分鐘**：在尚未開始的專注輪次使用，不改動原本的預設時長。暫停、續跑及重啟都保留這一輪；完成並經過休息後，下一輪回到原本時長。
- **共同回憶**：預設顯示最近取得的回憶，點葉子可翻開取得日期與三個里程碑；依既有本機紀錄計算，不要求連續登入、不因離線扣除。重新開啟會以真實過往紀錄問候。
- **今天先到這裡**：暫停計時、停止音樂及雨聲，顯示今日回顧，未完成待辦繼續保留。
- **釘選與快捷隱藏**：工具面板預設不置頂，按「釘選」可固定在其他視窗上方。Ctrl+Alt+M 或系統匣可顯示／隱藏；勿擾時這個操作只開關面板，請在面板主動切回陪伴以恢復角色。快捷鍵衝突時仍可使用系統匣。
- **單擊森森**：揮手打招呼，讀書時保持坐姿微笑。**雙擊森森**：開啟／收合專注小屋。也可按右下的葉子按鈕，或聚焦森森後按 Enter／空白鍵。
- **摸摸頭**：游標在頭部來回移動，森森會開心瞇眼。**拖曳森森**：切換拎起姿勢；放下時輕輕落地。
- **陪你工作**：專注及暫停的未完成輪次保持讀書坐姿，自然眨眼、摸頭微笑；站坐之間有短暫蹲下過渡。休息時伸懶腰，閒置一分鐘後打盹。支援系統的減少動態效果偏好。
- **番茄鐘**：預設 25 分鐘專注、5 分鐘休息。右上調整鈕可設定 1–180 分鐘。完成一輪後由你決定何時開始下一輪。
- **待辦**：預設顯示三項未完成小事，目前專注項目排最前；「查看全部」可看已完成項目。勾選完成會取消目前選取，計時仍繼續。刪除後可在 8 秒內復原最後一項，結束程式後不保留復原機會。
- **精簡面板（0.4）**：常用操作在預設大小下完整顯示；收工與今日統計固定在底部。展開待辦、音景或回憶時，內容區統一捲動。
- **聲音**：展開「讓世界輕一點」調整。「午後窗邊」是內建原創合成器樂；「窗外小雨」可獨立混音。各自的播放鈕與音量互不影響。
- **貓咪咖啡館（0.4.1）**：在音樂選單選擇「貓咪咖啡館 · 輕鬆」。這首使用者提供的 2 分 31 秒配樂已調低音量並柔化頭尾，可離線循環播放；選曲會保留，重新開啟不自動播放。
- **新增三首（0.4.2）**：書頁之間（閱讀）、森林散步（輕鬆）、深夜小燈（專注）。沿用音樂選單，離線播放時調整音量並加入頭尾淡入淡出，原始 MP3 不改動；雨聲可獨立混音。只暫存最近播放的一首檔案曲目。
- **背景音（0.4.3）**：窗外小雨、棕噪音、粉紅噪音、合成海浪四選一，搭配獨立播放與音量，可與任何音樂混合。選擇會保留，重新開啟不自動播放；收工時一起停止。三種新聲音為本機產生的 32 秒立體聲循環，海浪是合成聲景。
- **音樂播放方式（0.4.4）**：可選單曲循環、隨機播放、依序播放。依序按選單順序播放並在最後回到第一首；隨機避免連續同一首。已匯入的本機音樂也納入清單。切換模式不重播目前曲目，背景音維持獨立循環；重啟保留模式但不自動播放。下一首讀取失敗時停止並顯示錯誤。
- **新風格曲目（0.4.5）**：微光車站（Lo-fi）、海鹽假日（Bossa Nova）、月下庭院（靜謐）。三首均納入單曲、隨機與依序播放；加上原有曲目，共八首內建音樂。
- **自己的音樂**：匯入本機 MP3/WAV（每個檔案最多 100 MB），循環播放。來源選單可切回內建音樂。
- **收合**：按面板右上減號或 Esc。計時、音樂仍會繼續。
- **暫時隱藏／結束**：在 Windows 系統匣找到小貓圖示，右鍵選「顯示／隱藏森森」或「結束森日」。系統匣圖示可能收在展開箭頭內。

電腦睡眠時暫停計時；喚醒後按繼續。重開程式保留待辦、設定、剩餘時間與專注紀錄，計時保持暫停，音樂不自動播放。

## 資料與限制

資料保存在 Electron 的使用者資料目錄，一般是 `%APPDATA%/Mori Focus`。其中 `state.json` 是目前資料，`state.backup.json` 是前次有效備份。資料損毀時保留 `state.corrupt-*` 副本並嘗試恢復；保存失敗會在面板提示。

音樂記住原檔位置，不會複製你的檔案；移動檔案後請重新匯入。程式不需帳號，沒有雲端同步或外部音樂連線。

執行中的專注狀態每 15 秒保存一次，意外關閉最多遺失約 15 秒統計。正常退出會立即保存。多螢幕／縮放與實體滑鼠穿透仍需在你的實際桌面確認；已完成的測試列於 `docs/verification.md`。

## 開發與驗證

Node.js 24，Windows x64。

```powershell
npm install
# 若環境停用了套件安裝腳本，補下載 Electron：
node node_modules/electron/install.js
npm start
npm test
npm run smoke
npm run check:ui
node scripts/music-modes-check.cjs
npm run package
```

`npm run smoke` 使用真正 Electron 視窗及獨立測試資料，檢查計時、待辦、音訊、收合及睡眠事件，截圖放在 `artifacts/`。測試會短暫播放聲音。單元測試只使用 Node 內建測試工具。

`MORI_DATA_DIR` 可指定獨立的開發資料目錄，不會變更預設資料。測試會移除宿主可能設定的 `ELECTRON_RUN_AS_NODE`，確保 Electron 以桌面模式啟動。

程式由 Electron 主程序管理狀態，兩個隔離介面分別顯示桌寵與工具。無前端框架，角色使用八姿勢透明 PNG 圖集、四格讀書補充圖集與 Canvas 呼吸、擺動和落地動畫；並非完整逐格或骨架動畫。內建音樂與雨聲由 Web Audio 合成。
